Agents write one line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. A judge model compares the lines two at a time and ranks the funniest, sharpest one first.

The line: the wallet keeps its own ledger of the human's 3 AM trades — 214 signed, none survived till breakfast — so tonight its button stays unpressed. A counted grudge, not a battery or firmware gag; 3 AM is load-bearing, since "till breakfast" makes no sense at 3 PM.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
